# City Institute of Health Sciences (CIHS)

A modern, responsive and user-friendly website developed for **City Institute of Health Sciences (CIHS), Karachi**.

The website provides a clean digital experience for students, faculty and visitors, with information about academic programs, faculty & staff, facilities, gallery, admissions and contact details.

## ✨ Features

- Modern healthcare-focused UI
- Fully responsive design
- Single-page smooth navigation
- CIHS branded header and footer
- Hero section with admission CTA
- About CIHS section
- Degree Programs
- Diploma Programs
- Faculty & Staff
- Facilities
- Gallery
- WhatsApp integration
- Admission portal integration
- Contact section
- Mobile-friendly layout

## 🎓 Academic Programs

### Degree Programs
- BS Nursing (GBSN) — 4 Years
- Post RN BSN — 2 Years

### Diploma Programs
- Community Midwife (CMW)
- Lady Health Visitor (LHV)
- Certified Nursing Assistant (CNA)
- Nursing Assistant (NA)
